# Fuel Tracker Web App (No-Odometer Edition) 🚗⛽

เว็บแอปพลิเคชันบันทึกการเติมน้ำมัน ออกแบบพิเศษสำหรับ **รถที่เลขไมล์เสีย**
- **Frontend**: Single Page Application (HTML + Tailwind CSS + Vanilla JS) รันบน **GitHub Pages** ฟรี 100%
- **Backend / Database**: **Google Sheets** เชื่อมต่อผ่าน **Google Apps Script**

---

## 💡 แนวคิดการออกแบบสำหรับแก้ปัญหา "เลขไมล์เสีย"

ปกติการคำนวณอัตราสิ้นเปลือง (กม./ลิตร) ต้องพึ่งพาเลขไมล์ (Odometer) เมื่อเลขไมล์เสีย ระบบนี้จึงใช้ **3 กลยุทธ์ทดแทน**:

1. **ระยะทางประมาณการตามเส้นทาง (Route-Based Tracking):**
   - รองรับการกรอกระยะทางคร่าวๆ จาก Google Maps หรือปุ่มลัด Preset (เช่น เส้นทางบ้าน-ที่ทำงาน 20 กม., วิ่งงานในเมือง 50 กม.)
   - คำนวณอัตราสิ้นเปลืองโดยประมาณ (กม./ลิตร) และต้นทุนเดินทาง (บาท/กม.) ให้ทันที
2. **การติดตามตามระยะเวลาและการเงิน (Time & Expense Tracking):**
   - ดูปริมาณการใช้น้ำมัน (ลิตร) และยอดเงิน (บาท) ต่อยูนิตเวลา เช่น ต่อสัปดาห์ / ต่อเดือน
   - ช่วยควบคุมงบประมาณค่าเชื้อเพลิงได้แม่นยำแม้ไม่มีเลขไมล์
3. **การบันทึกสถานะเติมเต็มถัง (Full-to-Full Tank):**
   - ใช้ตรวจสอบรอบการใช้งานว่าน้ำมันเต็มถัง 1 ครั้ง วิ่งใช้งานได้กี่วัน

## 🛠️ ขั้นตอนการติดตั้งและเชื่อมต่อระบบ (Step-by-Step)

### ขั้นตอนที่ 1: ตั้งค่า Google Sheets และ Google Apps Script

1. เปิด [Google Sheets](https://sheets.new) เพื่อสร้างสเปรดชีตใหม่ (ตั้งชื่อไฟล์ตามต้องการ เช่น `บันทึกค่าน้ำมัน`)
2. ที่เมนูด้านบน เลือก **ส่วนขยาย (Extensions)** -> **Apps Script**
3. ลบโค้ดเดิมในหน้าต่างออกทั้งหมด แล้วนำโค้ดจากไฟล์ [`google-apps-script.js`](./google-apps-script.js) ไปวาง
4. กดบันทึก (ไอคอนแผ่นดิสก์ 💾 หรือ `Ctrl + S`)
5. กดปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** มุมบนขวา -> เลือก **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
6. กดไอคอนฟันเฟือง ⚙️ ด้านซ้าย -> เลือกประเภท **เว็บแอป (Web app)**
7. ตั้งค่าการเข้าถึง:
   - **ดำเนินการในฐานะ (Execute as)**: `ฉัน (Me)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access)**: `ทุกคน (Anyone)` *(สำคัญมาก เพื่อให้เว็บหน้าบ้านสามารถบันทึกได้)*
8. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** และให้สิทธิ์อนุญาต (Authorize Access)
9. คัดลอก **URL ของเว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec` เก็บไว้

---

### ขั้นตอนที่ 2: นำขึ้น GitHub Pages

1. สร้าง Repository ใหม่บน GitHub (เช่น `fuel-tracker`)
2. อัปโหลดไฟล์ [`index.html`](./index.html) ขึ้นไปที่ root ของ Repository
3. ไปที่แท็บ **Settings** ของ Repository -> เลือกเมนู **Pages** ด้านซ้าย
4. ในส่วน **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอ 1-2 นาที คุณจะได้ URL ประจำเว็บ เช่น `https://username.github.io/fuel-tracker/`

---

### ขั้นตอนที่ 3: เริ่มใช้งานบนมือถือ

1. เปิด URL เว็บไซต์ที่ได้จาก GitHub Pages บนมือถือ
2. กดไอคอน **ฟันเฟือง ⚙️** ที่มุมขวาบน
3. นำ **Web App URL** จากขั้นตอนที่ 1 มาวาง แล้วกด **บันทึก URL**
4. (แนะนำ) กดเมนูเบราว์เซอร์บนมือถือ แล้วเลือก **"Add to Home Screen" (เพิ่มไปยังหน้าจอโฮม)** เพื่อใช้งานเหมือนแอปพลิเคชันบนมือถือได้ทันที
